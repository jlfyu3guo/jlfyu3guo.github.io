# 欢迎使用「知识库」

这个网站用于**存储和检索微信公众号的知识类文章**。你可以把收藏的公众号文章（技术、生活、学习方法等）转成 Markdown 后放入 `content/` 目录，构建时自动生成索引。

## 功能

- **分类浏览**：每篇文章一个分类，点击分类标签即可筛选
- **全文搜索**：支持标题、摘要和标签搜索
- **竖版阅读**：文章按公众号文章样式排版，手机阅读舒适
- **原文链接**：每篇文章保留公众号原文链接，方便核对

## 如何添加文章

1. 在 `content/` 目录新建 `.md` 文件
2. 开头用 `---` 包裹的元信息（frontmatter）注明标题、日期、分类、标签
3. 正文用标准 Markdown 书写
4. 推送到 GitHub，网站自动重新构建发布
